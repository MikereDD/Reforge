# Supported Installer and Rescue Targets

## Operating Systems

1. Windows 11
2. Arch Linux
3. Linux Mint
4. Ubuntu LTS
5. Fedora Workstation
6. Debian

## Rescue / Diagnostic Targets

- Reforge Rescue / SystemRescue foundation
- Rescuezilla
- GParted Live
- Memtest86+

## Policy

Reforge is network-first. These entries describe supported targets, not a requirement to store every corresponding ISO on the USB key.

Where practical, Reforge should retrieve current approved payloads from official upstream sources and verify them before use.
