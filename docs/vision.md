# Vision

Reforge is intended to be a practical reinstall and recovery toolkit that helps
people avoid losing data, wasting time, and repeatedly rebuilding machines from
scratch without a plan.

## Product Direction

Reforge should feel like a dependable Swiss-army knife for:

- reinstall preparation
- recovery boot tasks
- diagnostics
- backup and restore
- multi-distro installation
- post-install bootstrap

## Guiding Principles

1. **Safety first** — help the user preserve data before destructive actions.
2. **Clarity over cleverness** — a clean guided flow beats over-automation.
3. **Portable by default** — designed around a bootable USB workflow.
4. **Extensible** — additional distros, tools, and profiles should be easy to add.
5. **Maintainable** — versioned manifests, documented structure, simple scripts.
